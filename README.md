## Selected Work

### [gempa-indonesia-tableau](https://github.com/GirvanAzharXD/gempa-indonesia-tableau)
Maps and trends earthquakes in Indonesia, M4.5+, 2024-2026. 2,280 events from the USGS catalog.

[![Tableau Public](https://img.shields.io/badge/Tableau_Public-View_Dashboard-E97627?style=flat-square&logo=tableau&logoColor=white)](https://public.tableau.com/app/profile/mochamad.girvan.azhar/viz/GempaBumidiIndonesia20242026/GempaBumidiIndonesia20242026)

### [harga-cabai-rawit-merah-looker-studio](https://github.com/GirvanAzharXD/harga-cabai-rawit-merah-looker-studio)
Tracks red chili prices across 32 provinces, Jan 2025-Nov 2026, from PIHPS Bank Indonesia data.

[![Looker Studio](https://img.shields.io/badge/Looker_Studio-View_Dashboard-4285F4?style=flat-square&logo=lookerstudio&logoColor=white)](https://datastudio.google.com/reporting/4a6c307f-a88a-40bf-887b-83b86f692efc)

### [dana-desa-jawa-barat-power-bi](https://github.com/GirvanAzharXD/dana-desa-jawa-barat-power-bi)
Tests whether larger village funds mean lower poverty across 19 districts in West Java, 2024. Built from DJPK and BPS data.
