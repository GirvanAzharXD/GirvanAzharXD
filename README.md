### ⚡ About Me

I'm an Informatics graduate who turns public data into dashboards that answer real questions.

- 🎓 **Education:** S1 Informatika, Universitas Gunadarma (GPA: 3.52/4.00)
- 📊 **Focus:** Data Analysis, Machine Learning, and Dashboard Visualization
- 📌 **Latest work:** Power BI, Tableau, and Looker Studio dashboards on [girvanazhar.vercel.app](https://girvanazhar.vercel.app/), built from official Indonesian public data (DJPK, BPS, PIHPS Bank Indonesia, USGS)
